# 田舎家サンプルの利用説明

2026年10月4日／検証版20261004-3

このサンプルは、3つのデザインと日常の編集操作を比べるためのものです。変更は同じブラウザの中だけに保存します。

## 編集の流れ

1. 上部の「編集デモ」を開き、編集する項目を選びます。
2. 内容を変更し、「変更を保存」で変更前後を確認します。
3. 修正するときは「編集へ戻る」、反映するときは「このブラウザに保存」を押します。

保存前に閉じると「反映する／反映せずに終了／編集を続ける」を選べます。「反映する」は確認画面へ進み、保存で反映します。「反映せずに終了」は編集中の変更を取り消します。ブラウザのタブ終了・再読み込みは標準の確認が出ます。「JSONを書き出す」で内容と写真をひとつのファイルとして保管できます。容量不足の場合は編集を残すので、写真を減らすなどして保存し直せます。

## お品書きとお知らせ

品名・価格・注記や、記事の日付・タイトル・本文を変更できます。非表示は内容を残し、後から再表示できます。お品書きはカテゴリ内でカードを長押しして移動します。↑↓ボタンでも並び替えられます。ドラッグのたびに確認画面は開きません。連続で並び替えや他の編集を行い、最後に「変更を保存」→「このブラウザに保存」でまとめて反映します。

お知らせは非表示・下書き・終了済みを含め20件まで保存し、公開中のものから最大10件を表示します。ピックアップを先に、記事の日付が新しい順に表示します。記事の日付と予約公開日時は別です。一覧のタイトルを押すと詳細が開き、PCでは画面中央・ヘッダの下の固定位置、スマホでは画面下部に表示します。外側を押すか「閉じる」で閉じます。

「バッジ・掲載期間の設定」を開くと、おすすめ・期間限定・キャンペーン・数量限定・売り切れ・受付停止・終了を複数選択できます。自由入力は各項目に1つ、全角6文字までです。NEWを付けるかどうかも選べます。

NEWは、最初の公開または「今回の公開でNEWを付け直す」を選んだ公開から数えます。通常の価格・本文・バッジ変更では延長しません。自動の場合の日数は「表示設定」で共通の1つを指定します。手動の場合はチェックを外すまで残ります。

公開日時は空欄なら即時、日時を指定すると予約できます。終了日時は空欄なら自動終了しません。「終了」バッジを付けるだけでは非表示になりません。

## 写真とお問い合わせ

「写真」でメイン・うどん・外観・御膳・店内の画像を差し替えます。店内写真は掲載する構成で使用する枠です。お知らせの写真は任意で、取り外しもできます。JPEG・PNG・WebP、8MBまで選べます。保存時に容量を整え、表示枠の中央を基準に切り取ります。文字入りのお品書き原本は全体を別途閲覧できます。

お問い合わせは名前、メールと再入力、種類、本文を入力する見本です。架空の内容を使ってください。メールは送信せず、このブラウザ内に受付を保存します。「お問い合わせ」で対応状況と内部メモを管理できます。

最終更新日は公開ページの「店舗・アクセス」に表示します。問い合わせの受付や内部メモだけの変更では更新しません。「表示確認時刻」は予約・NEW・終了を試すための見本専用機能です。試した後は「現在時刻に戻す」を押してください。


20261004-3では、お品書きの品名横に長押しの目印を表示し、移動先の品名付近で離しても置ける判定に修正しました。カード中央まで越える必要はありません。「ここに移動」の線を表示し、並び替えは最後の保存まで公開側へ反映しません。未保存で閉じるボタン・Escape・背景を押す場合は終了前の確認を表示します。共通SITE BASEと違い、田舎家では確定前の編集を終了すると作業内容を保存せず取り消します。
