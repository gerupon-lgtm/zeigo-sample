# 田舎家 — 3つのデザイン見本

和の雰囲気が異なる3案を比較し、価格・写真・お知らせなどの編集を試せるサンプルです。

検証版：20261004-4。公開見本：https://gerupon-lgtm.github.io/zeigo-sample/

上部の「編集デモ」から操作できます。変更内容を確認し、「このブラウザに保存」で3案すべてに反映します。未保存で閉じると変更は取り消されます。

保存先は使用中のブラウザだけです。他の端末への共有や実店舗への公開は行いません。お問い合わせも架空の内容でお試しください。実際のメールは送信しません。

- お品書き：名称・価格・追加・非表示・並び替え、複数バッジ、公開期間。
- お知らせ：最大20件保存・10件表示、写真・ピックアップ、タイトルから詳細表示。
- 写真：ページ内の画像枠ごとの差し替え。容量を整え、中央でトリミング表示。
- 営業情報：営業時間・定休日。
- お問い合わせ：見本の受付履歴・対応状況・内部メモ。
- 表示設定：NEWの日数と、予約・終了を試すための確認時刻。

NEWは付けない／付けるを選択でき、付ける場合は自動で消す／手動で外すを選べます。通常の編集では期間を延長しません。「終了」などのバッジは表示する言葉で、掲載終了は日時で別に設定します。

詳しい操作は [サンプルの利用説明](docs/zeigo-sample-guide.md) を参照してください。

未保存の編集を閉じる場合は、反映・反映せず終了・編集継続を選べます。反映は変更確認後の保存で確定します。並び替えは移動先の品名付近で離すと置けます。


編集と確認の画面は、内容だけをスクロールして確認できます。閉じるボタンと、保存・編集へ戻る・確定・JSON関連の主な操作は画面内に残ります。PC・スマホとも同じ配置です。
